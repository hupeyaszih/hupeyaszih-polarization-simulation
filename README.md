# Hupeyaszih Polarization Simulation (HPS)

**Hupeyaszih Polarization Simulation (HPS)** is a dynamic graph based idea spreading simulation that aims to simulate how ideas spread and what effects their spreading dynamics; furthermore, it aims to demonstrate how echo chambers exist and evolve by time.

> [!NOTE]
> **Current Phase: Literature Review and Searching**

## What It Is 

The simulation is written in C. As described above, HPS is graph based idea spreading simulation.
